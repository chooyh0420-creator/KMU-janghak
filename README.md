# 장학복지팀 오시는 길

계명대학교 성서캠퍼스 장학복지팀(바우어신관 1층 3105호)까지의 길을
실제 지도 위에서 애니메이션으로 보여주는 안내 페이지입니다.

- 지하철(계명대역 / 강창역), 버스, 자가용 **4가지 경로**
- 도트 캐릭터가 경로를 따라 이동 — 자가용은 **자동차 → 주차 후 학생**으로 전환
- 경유 지점마다 `7분 정문 진입` 형식의 말풍선
- 경로는 OpenStreetMap 도로망에서 **직접 계산한 실제 최단 경로**

`index.html` **파일 하나가 전부입니다.** 빌드 과정도, 설치할 것도 없습니다.

- 다른 페이지에 넣기 →
  ```html
  <iframe src="/index.html" style="width:100%;height:1800px;border:0"></iframe>
  ```

### 사무실 망에서도 안전합니다

지도 라이브러리(Leaflet)와 배경 지도 데이터가 **파일 안에 들어 있어서**,
외부 접속이 막힌 환경에서도 그대로 동작합니다.

| 외부 요청 | 막히면 | 결과 |
|---|---|---|
| 지도 타일 (cartocdn) | 내장 벡터 지도로 자동 대체 | 정상 동작 |
| 글꼴 (jsdelivr) | 맑은 고딕으로 대체 | 정상 동작 |

전체 차단 상태에서 4개 경로 모두 동작하는 것을 확인했습니다.

## 고치는 방법

전부 `index.html` 안에 있습니다. 아래 표에서 필요한 곳을 찾아 고치세요.

| 고치고 싶은 것 | 찾을 위치 | 검색어 |
|---|---|---|
| 말풍선 문구, 단계 설명 | `META` 객체 | `const META=` |
| 운영시간, 전화번호, 주소 | 방문 전 확인 카드 | `운영시간` |
| 버스 노선 번호 | 버스 카드 | `busline` |
| 실내 안내 (몇 층, 어느 복도) | 건물 안내 카드 | `건물에 들어오신 뒤` |
| 지도 타일 사용 여부 | 스크립트 상단 | `USE_TILES` |
| 캐릭터 옷 색 | 색상표 | `const PAL=` |
| 경로 좌표 | 자동 생성 데이터 | `const ROUTE_DATA=` |

### 예시 — 말풍선 문구 바꾸기

```js
gangchang:{mode:"도보",speed:67,vehicle:false,
  stops:[{i:0,  t:"강창역",           side:"down"},
         {i:13, t:"남문 진입",         side:"down"},   // ← 이 문구를 고치면 됩니다
         {i:22, t:"바우어신관 3105호", side:"up", goal:true}],
```

- `i` : 경로 좌표의 몇 번째 지점에 말풍선을 붙일지 (0부터 시작)
- `t` : 말풍선에 쓸 문구
- `side` : `up`이면 마커 위, `down`이면 마커 아래
- 소요 시간(`7분`)은 경로 길이로 **자동 계산**되니 적지 않아도 됩니다

### 예시 — 캐릭터 색 바꾸기

```js
const PAL={k:"#22262B",  // 머리카락, 신발
           s:"#F5CBA3",  // 피부
           n:"#16325C",  // 후드집업
           w:"#FFFFFF",  // 티셔츠
           r:"#E4572E",  // 백팩끈, 자동차
           q:"#3C4A5E"}; // 청바지
```

## 경로를 다시 계산하려면

출발지를 바꾸거나 캠퍼스 도로가 바뀌었을 때만 필요합니다.
문구만 고칠 거라면 이 단계는 건너뛰세요.

```bash
cd tools
python rebuild_routes.py           # 저장된 지도 데이터 사용 (인터넷 불필요)
python rebuild_routes.py --fetch   # OpenStreetMap에서 최신 데이터 받아오기
```

출발지·목적지는 `tools/rebuild_routes.py` 위쪽 `PLACES`에서 고칩니다.

```python
BAUER = (35.854248, 128.4861048)   # 도착지: 바우어신관
GATE  = (35.852625, 128.487141)    # 정문

PLACES = {
    #  이름          출발 좌표                 이동수단  속도   경유지
    "gyemyeong": ((35.851474, 128.491956), "foot",  67,  None),
    "car":       ((35.851680, 128.490900), "drive", 330, GATE),
}
```

실행하면 최단 경로를 계산해 `index.html`의 좌표를 자동으로 갱신합니다.
파이썬 표준 라이브러리만 쓰므로 따로 설치할 패키지는 없습니다.

> **주의** — 좌표는 `(위도, 경도)` 순서입니다. 구글맵에서 복사하면 이 순서예요.
> 정문(`128.487141`)과 버스정류장 '계명대학교정문앞'(`128.485212`)은
> **약 174m 떨어진 다른 지점**이니 헷갈리지 마세요.

## 확인이 필요한 내용

아래는 인터넷 자료를 바탕으로 채운 값이라, 실제와 다를 수 있습니다.
사무실에서 확인하고 고쳐 주세요.

- [ ] **전화번호** — 현재 `053-580-6091~4` (조직도 기준).
      장학 자가진단 사이트에는 `6096~6098`로 되어 있어 서로 다릅니다
- [ ] **실내 안내** — "1층 로비 → 왼쪽 복도 → 3105호"는 추정입니다
- [ ] **강창역 출구 번호** — 현재 "계명대 방향 출구"로만 표기
- [ ] **남문 위치** — 강창역 경로의 '남문 진입' 지점 좌표가 미확인 상태입니다
- [ ] **차량 진입 가능 문** — 정문 외에 다른 문으로만 가능한지
- [ ] **버스 노선** — `급행1 · 520 · 524 · 527 · 564 · 655 · 성서2`
      (2026-08-01 기준, 개편 시 변경될 수 있음)

## 폴더 구성

```
├── index.html                  ← 실제 페이지 (이 파일 하나면 됩니다)
├── tools/
│   ├── rebuild_routes.py       ← 경로 재계산 스크립트
│   ├── osm_raw.json            ← OpenStreetMap 원본 데이터
│   └── index.cdn.html          ← 라이브러리를 CDN에서 불러오는 가벼운 판(참고용)
└── vendor/
    ├── leaflet.js              ← 지도 라이브러리 원본
    └── leaflet.css
```

`vendor/`의 파일은 이미 `index.html` 안에 포함되어 있습니다.
버전을 올릴 때 참고하시라고 원본을 함께 뒀습니다.
